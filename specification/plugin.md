# プラグインの仕様

herdr のサイドバーの Agents 欄に出るエージェント名を、「動物の絵文字＋エージェント名」（例: `🐶 kiro`）にする。

## 動物の決め方

- 使う動物と順番は、設定ファイル `animals.conf` で決める。
  - 置き場所は `herdr plugin config-dir asaty94.animals` が示すフォルダ。なければ、初回に `animals.conf.example` から作る。
  - 絵文字を、空白か改行で区切って書く。`#` から行末まではコメント。同じ絵文字を 2 回書いたら、先のものだけを使う。
- 新しく見つかったエージェントには、動いているエージェントが使っていない動物のうち、設定でいちばん先にあるものを付ける。
- 一度付けた動物は、そのエージェントが動いている間は変えない。エージェントの種類が変わったら（例: `claude` を終えて同じ端末で `kiro` を起動）、動物はそのままで名前だけ直す。
- エージェントが終わると、その動物は空き、次のエージェントに使える。ペインに付けた名前は消す。
- 動いているエージェントが動物より多いときは、先頭の動物から順に重ねて使う。
- 設定から消した動物を使っているエージェントには、上の決まりで動物を付け直す。設定が空なら、すべて元の名前に戻す。
- 設定の変更は、次にイベントが起きたとき、またはアクション「Animals: 動物を付け直す」を実行したときに反映する。

## 動くとき

herdr の起動時（`startup`）と、イベント `pane.agent_detected`・`pane.agent_status_changed`・`pane.exited`・`pane.closed` のたびに、動いているすべてのエージェントを見直す。

- 名前は `herdr pane report-metadata --display-agent` で送る。表示だけを変え、エージェントの状態の判定には影響しない。
- エージェントは端末の ID（`terminal_id`）で見分け、割り当てを状態フォルダ（`HERDR_PLUGIN_STATE_DIR`）の `assigned.tsv` に保存する。
- エージェントの一覧を取れなかったときは、何も変えない。
- 同時に複数のイベントが来ても、1 つずつ順に処理する。

## 必要なもの

herdr 0.9.5 以上、bash、[jq](https://jqlang.org/)。macOS と Linux。
